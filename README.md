# .github

[![studio2201 gate](https://github.com/idlescreen/.github/actions/workflows/studio2201.yml/badge.svg)](https://github.com/idlescreen/.github/actions/workflows/studio2201.yml)

IdleScreen organization metadata — the org profile
(`profile/README.md` is what renders on github.com/idlescreen) and shared
brand assets (`profile/assets/`). Part of
[IdleScreen](https://idlescreen.github.io) — modular Wayland screensavers
for Linux.

Nothing to install — this repo configures the org's GitHub presence.
